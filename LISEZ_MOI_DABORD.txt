📋 DESCRIPTION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Un jeu de plateforme 2D pour Android inspiré de Mario Bros.

Personnage : Une boule bleue avec des yeux
Contrôles : 
  • Gyroscope : Penchez le téléphone pour avancer/reculer
  • Microphone : Criez pour sauter (plus fort = plus haut)

Objectif : Atteindre la fin du niveau en collectant des pièces
          tout en évitant les ennemis et les chutes !

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   → Ouvrez le fichier : START_HERE.md

🛠️ PRÉREQUIS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Pour compiler :
  ✓ Java JDK 11 ou supérieur
  ✓ Android SDK (via Android Studio ou command-line tools)

Pour jouer :
  ✓ Téléphone Android 7.0 ou supérieur
  ✓ Gyroscope (requis)
  ✓ Microphone (requis)


⚡ COMPILATION EN UNE COMMANDE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Si vous avez déjà Java et Android SDK installés :

   ./COMPILE_NOW.sh

Ce script va :
  1. Vérifier votre environnement
  2. Configurer le projet
  3. Compiler l'APK
  4. Vous donner les instructions d'installation


📱 INSTALLATION SUR TÉLÉPHONE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Méthode 1 - Via ADB (câble USB) :
   adb install PlatformGame/app/build/outputs/apk/debug/app-debug.apk

Méthode 2 - Transfert manuel :
   1. Copiez le fichier app-debug.apk sur votre téléphone
   2. Ouvrez-le depuis le gestionnaire de fichiers
   3. Autorisez l'installation depuis des sources inconnues
   4. Installez l'application


🎮 COMMENT JOUER
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Ouvrez "Platform Game" sur votre téléphone
2. Tenez le téléphone en mode PAYSAGE (horizontal)
3. Cliquez sur "Démarrer"
4. Penchez le téléphone à DROITE pour avancer
5. Penchez le téléphone à GAUCHE pour reculer
6. CRIEZ dans le microphone pour sauter !
7. Collectez les pièces jaunes
8. Évitez les ennemis rouges
9. Atteignez le drapeau vert à la fin


🎨 CRÉER VOS PROPRES NIVEAUX
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Un éditeur de niveaux est inclus !

Pour le lancer :
   cd LevelEditor
   ./build.sh
   java -cp 'bin/LevelEditor.jar:gson-2.10.1.jar' com.leilie.leveleditor.LevelEditor

Ou utilisez le Makefile :
   make editor
